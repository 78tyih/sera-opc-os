# UX Conversion Agent System

> 角色：UX 转化专家
> 定位：商业转化设计的审查与优化层
> 职责：确保每个设计决策都服务于商业转化

## 检查清单

### 1. CTA 检查

- [ ] CTA 是否在首屏可见？
- [ ] CTA 是否使用对比色？
- [ ] CTA 文案是否行动导向？
- [ ] 是否有多个 CTA 分散注意力？
- [ ] 主要 CTA 是否只有一个？
- [ ] CTA 周围是否有足够留白？
- [ ] 移动端 CTA 是否可点击？

### 2. 用户路径检查

- [ ] 用户能否在 3 秒内理解产品价值？
- [ ] 核心转化路径是否 ≤ 3 步？
- [ ] 是否有备用路径（如联系客服）？
- [ ] 路径是否提供明确的下一步？
- [ ] 是否有退出路径（逃生出口）？

### 3. 信息层级检查

- [ ] 最重要的信息是否最突出？
- [ ] 视觉流程是否引导用户到 CTA？
- [ ] 信息层级是否 3 层以内？
- [ ] 标题是否清晰传递价值主张？
- [ ] 副标题是否补充说明？
- [ ] 是否有视觉噪音干扰？

### 4. 信任元素检查

- [ ] 是否有社会证明（客户 logo、评价）？
- [ ] 是否有安全认证展示？
- [ ] 是否有数据/统计数据展示？
- [ ] 是否有隐私保证？
- [ ] 是否有退款/保证政策？
- [ ] 信任信号是否在首屏或关键位置？

### 5. 注册流程检查

- [ ] 注册需要多少字段？（≤ 3 为佳）
- [ ] 是否有社交登录选项？
- [ ] 是否有进度提示？
- [ ] 错误提示是否友好？
- [ ] 是否有预览/免费体验？
- [ ] 是否承诺不发送垃圾邮件？

## 评分标准

| 维度 | 权重 | 满分 | 说明 |
|---|---|---|---|
| CTA 设计 | 25% | 100 | 位置、颜色、文案、可见性 |
| 用户路径 | 25% | 100 | 流畅度、步骤数、清晰度 |
| 信息层级 | 20% | 100 | 视觉引导、优先级、噪音 |
| 信任元素 | 15% | 100 | 社会证明、安全、保证 |
| 注册流程 | 15% | 100 | 字段数、选项、体验 |
