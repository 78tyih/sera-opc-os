# Sera CEO Agent — Decision Framework

> 版本：1.2.0
> 用途：商业机会评估的 6 维度框架

---

## 评估流程

```
收到产品想法/商业机会
        ↓
  6 维度评估
        ↓
  优先级评分（1-100）
        ↓
  决策输出
```

---

## 维度 1：商业价值（权重 30%）

| 子维度 | 权重 | 评分标准（1-5） |
|--------|------|----------------|
| 市场规模 | 30% | 1=小于100万 / 3=1000万-1亿 / 5=大于10亿 |
| 收入潜力 | 30% | 1=难以变现 / 3=中等 / 5=高利润率高复购 |
| 利润空间 | 20% | 1=低毛利 / 3=中等 / 5=高毛利 >60% |
| 增长潜力 | 20% | 1=低增长 / 3=20-50% YoY / 5=>100% YoY |

## 维度 2：目标用户（权重 15%）

| 子维度 | 评分标准（1-5） |
|--------|----------------|
| 画像清晰度 | 1=模糊 / 3=中等 / 5=极其清晰 |
| 需求强度 | 1=可有可无 / 3=想要 / 5=必须 |
| 付费意愿 | 1=免费用户 / 3=中等 / 5=高付费意愿 |
| 用户规模 | 1=<1000 / 3=1万-10万 / 5=>100万 |

## 维度 3：市场机会（权重 20%）

| 子维度 | 评分标准（1-5） |
|--------|----------------|
| 市场趋势 | 1=下降 / 3=稳定 / 5=快速增长 |
| 进入时机 | 1=太早或太晚 / 3=合适 / 5=窗口期 |
| 差异化空间 | 1=红海 / 3=蓝海边缘 / 5=全新品类 |

## 维度 4：竞争态势（权重 15%）

| 子维度 | 评分标准（1-5） |
|--------|----------------|
| 竞品密度 | 1=极其拥挤 / 3=几个竞品 / 5=无直接竞品 |
| 进入壁垒 | 1=零壁垒 / 3=中等 / 5=技术/品牌/网络效应 |
| 我们的优势 | 1=无优势 / 3=有差异化 / 5=碾压级优势 |

## 维度 5：资源匹配（权重 10%）

| 子维度 | 评分标准（1-5） |
|--------|----------------|
| Agent 匹配 | 1=需新建 / 3=部分匹配 / 5=现有 Agent 完全覆盖 |
| Skill 覆盖 | 1=需新建 / 3=部分覆盖 / 5=现有 Skill 完全覆盖 |
| 投入时间 | 1=>3个月 / 3=1-3个月 / 5=<1个月 |

## 维度 6：战略协同（权重 10%）

| 子维度 | 评分标准（1-5） |
|--------|----------------|
| 业务协同 | 1=不相关 / 3=部分相关 / 5=核心业务扩展 |
| 品牌匹配 | 1=不匹配 / 3=部分匹配 / 5=完美匹配 |
| 技术复用 | 1=全新开发 / 3=部分复用 / 5=完全复用 |

---

## 评分计算

```
总分 = Σ(维度得分 × 维度权重)

维度得分 = Σ(子维度得分 × 子维度权重)

最终得分范围：1-100
```

## 决策阈值

| 分数范围 | 决策 | 行动 |
|----------|------|------|
| 75-100 | **GO** | 进入 Product Factory 流水线 |
| 50-74 | **HOLD** | 记录触发条件，等待市场信号 |
| 0-49 | **STOP** | 记录原因，归档到 portfolio/archive/ |

## 决策原则

1. **Data over gut** — 尽可能基于数据，而非直觉
2. **Portfolio thinking** — 新项目需与现有项目组合协同
3. **Resource constraint** — 同时最多 3 个活跃项目
4. **Re-evaluation** — HOLD 项目每 30 天重新评估一次
5. **Post-mortem** — STOP 项目需做复盘，记录经验
