# trading-analysis

## Purpose
交易分析 Skill：交易数据复盘、胜率/盈亏比统计、策略回测报告、订单流与市场结构解读。作为 trading-agent 的核心分析引擎。

## When to use
- 「复盘这笔交易 / 这个策略」
- 「统计我最近的胜率 / 盈亏比」
- 「帮我回测这个策略」
- 「ATAS / 订单流数据怎么解读」
- 「分析 [标的] 的市场结构」

## Inputs
- 交易记录（CSV / Excel / 券商导出 / 手输）
- 策略参数（入场/出场/风控规则）
- 行情 / 订单流数据（ATAS 导出 / 交易所 API）
- 分析需求（复盘 / 统计 / 回测 / 结构分析）

## Outputs
- 复盘报告：单笔或批量交易逐笔标注（好/坏/运气）
- 统计指标：胜率、盈亏比、期望值、最大回撤、Sharpe
- 回测报告：净值曲线、参数敏感性、风险指标
- 市场结构分析：订单流解读、关键位、量价关系

## Workflow
```
1. 数据摄入：读交易记录 / 行情数据（CSV/Excel/API）
2. 复盘模式：逐笔标注 → 总结规律（做对了什么/做错了什么）
3. 统计模式：计算胜率/盈亏比/期望/回撤 → 输出指标卡
4. 回测模式：定义策略 → 回放历史 → 净值/风险报告
5. 结构模式：订单流/量价 → 市场结构判断
6. 报告归档 → sera-knowledge-sync
```

## 统计口径（固定，避免口径漂移）
- **胜率** = 盈利笔数 / 总平仓笔数
- **盈亏比** = 平均盈利 / 平均亏损
- **期望值** = 胜率 × 平均盈利 − (1−胜率) × 平均亏损
- **最大回撤** = 净值峰值到谷值的最大跌幅
- 全部按已实现平仓计算，浮盈不计入

## Dependencies
- `sera-finance-suite`（依赖，行情/估值数据辅助）
- `sera-knowledge-reader`（历史研究报告检索）
- 数据源：ATAS / 交易所 API / 券商导出（待接入）

## Examples
- 「复盘 2026-08 的 20 笔交易」→ 逐笔标注 + 规律总结
- 「统计我的胜率和盈亏比」→ 指标卡（口径见上）
- 「回测 突破策略 过去 6 个月」→ 净值曲线 + 风险报告
