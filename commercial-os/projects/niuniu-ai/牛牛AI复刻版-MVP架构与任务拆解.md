## 1. 产品本质（一句话）

**一个挂在 MT5 上的 AI 交易副驾：分析给建议、风控把关口、人来拍板、系统执行、全程留痕复盘。**

核心闭环（手册蒸馏）：

```
行情分析 → 风控审核 → 用户确认 → 交易执行 → 日志复盘
```

合规红线（沿用代理期原则）：**无收益承诺、风险可见、AI 只做建议与审核，下单前必须有人类确认环节**。

## 3. MVP 范围（V0，4 周）

**做**：模块 2（三脑管线）+ 5（决策日志）+ 6（MT5 连接，只做市价单/平仓）+ 7（截图分析 + 一键布局确认）+ 3（基础风控：日次数 + 最大持仓 + 固定止损止盈）

**不做**（V1 再说）：EA 策略市场、克隆分析师 UI、新闻过滤自动化（先手动名单）、牛气值精细化计费（先套餐授权）

## 4. 技术架构

```
┌────────────┐   MQL5 EA    ┌──────────────┐   HTTPS    ┌─────────────┐
│   MT5 终端  │ ◄─────────► │  本地网关 GW   │ ◄────────► │  AI 服务层   │
│ (用户电脑)  │  心跳/下单   │ (Python 常驻) │            │ (三脑管线)   │
└────────────┘              └──────┬───────┘            └──────┬──────┘
                                   │ SQLite                     │ 读写
                            ┌──────▼───────┐            ┌───────▼──────┐
                            │ kernel 本地库 │            │ Memory Kernel │
                            │ (日志/设置)   │            │ 经验/规则/决策 │
                            └──────────────┘            └──────────────┘
```

- **EA（MQL5）**：账户/持仓/报价采集、接收并执行已确认指令。最小指令集：`OPEN / CLOSE / MODIFY_SLTP / HEARTBEAT`
- **本地网关（Python）**：鉴权、风控硬校验（网关层再查一次，不信赖云端）、指令队列、断线重连
- **AI 服务层**：AI-1 分析 → AI-2 审核（否决权）→ AI-3 持仓诊断；模型走 `runtime/model-router.yaml`：分析/提炼 → DeepSeek，代码/工具 → Codex，界面 → Trae
- **经验闭环**：每次"历史订单提炼"结果写入 kernel Experience（带 root_cause），≥3 次同因验证自动晋升 Rule，下一轮 AI-2 审核自动携带

## 5. 任务拆解（按模型路由分工）

| 周 | 任务 | 负责 |
|----|------|------|
| W1 | MT5 EA 最小指令集 + 本地网关心跳/下单链路打通 | Codex |
| W1 | 三脑提示词体系 v0（从手册 §四/§十 蒸馏 AI-1/2/3 提示词） | DeepSeek |
| W2 | 客户端 Dashboard（实时面板：账户/持仓/日志流） | Trae |
| W2 | kernel 对接：决策日志落 events 表、风控规则落 Rule 对象 | Codex |
| W3 | AI 分析闭环：截图→报告→一键布局→人工确认→执行 | Codex + DeepSeek |
| W3 | 历史订单提炼器（CSV → 经验 → 规则晋升演示） | DeepSeek |
| W4 | 端到端联调 + 合规审查（无收益承诺/风险提示）+ 灰度 3 个种子用户 | 全员 + 创始人 |

## 6. 验证清单（DoD）

1. EA 心跳稳定 ≥24h，断线自动重连
2. 一键布局必须经人工确认才下单（合规硬约束）
3. 每笔 AI 建议在三脑日志中可追溯到具体提示词与风控结论
4. 历史订单提炼 ≥3 次同根因后，kernel 自动晋升 Rule 并在下一轮审核中生效
5. 官网订阅页（已有）与新客户端激活码打通
