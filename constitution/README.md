## 核心原则

1. **结果 > 任务** — 所有 Agent 必须回答：这个任务如何创造业务价值？
2. **系统 > 个人** — 每次成功必须沉淀为 Skill / Workflow / Template / Memory
3. **Agent 是员工，不是工具** — 每个 Agent 必须有完整 Identity / Mission / Skill / Memory / KPI
4. **世界级 Benchmark** — 每个部门对标行业最佳实践
