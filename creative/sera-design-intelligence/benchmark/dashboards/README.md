- 数据分析仪表盘
- 业务监控面板

- 实时数据可视化

## 评分要点

仪表盘设计强调数据可读性和决策效率，评分时重点关注：
- 数据可视化质量
- 信息层级与布局
- 交互流畅度
- 自定义与灵活性
