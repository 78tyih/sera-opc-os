# Fintech Design Benchmark Cases

金融科技（Fintech）设计基准案例库。

## 收录范围

- 支付平台
- 数字货币/加密货币交易平台
- 银行及金融服务
- 投资理财平台
- 保险科技

## 评分要点

Fintech 设计强调信任感、安全性和专业性，评分时重点关注：
- Trust Level 权重较其他行业更高
- 数据可视化清晰度
- 合规性展示与透明度
- 交易流程的可用性
