# Trading Platform Design Benchmark Cases

交易平台设计基准案例库。

## 收录范围

- 股票/证券交易平台
- 加密货币交易所
- 衍生品/期货交易平台
- 自营交易（Prop Firm）平台
- 机构交易终端
- 外汇/差价合约平台

## 评分要点

交易平台设计强调信任感、数据密度和专业执行能力，评分时重点关注：

- **Trust Level（信任水平）权重更高**：交易涉及资金安全，信任是核心转换因素
- **Technical Execution（技术执行）为关键维度**：实时数据展示、图表渲染、性能稳定性直接影响交易体验
- Order Flow Visibility：订单流可见性和状态反馈
- Data Density：信息密度与数据可视化质量
- Trust Signals：合规展示、安全认证、资金保障说明
