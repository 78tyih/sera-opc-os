# HTX OTC Desk — Financial Premium Landing v1

**Design Case Study · 2026-07/08**

> 案例编号：`financial-premium-landing-v1`
> 项目类型：金融 OTC 服务 Landing Page
> 核心风格：Institutional Trust · Premium Fintech · Clean Hierarchy

---

## 1. Brand Positioning

### 关键词
```
Institutional · Trust · Liquidity · Professional · Secure · Compliant
```

### 品牌人格
HTX OTC Desk 的设计基调是**机构级金融服务的可信感**，而非消费级金融产品的促销感。

- 不 aggressive：不出现"收益""暴涨""套利""保本""秒到"等误导表达
- 不炫耀：不把后台合作方和银行链路做成视觉焦点
- 稳：首屏重心放在交易方向与客户动作，不放复杂图表
- 清晰：客户 3 秒内理解"这是什么业务、我能不能做"

### 页面定位（四合一）
| 角色 | 说明 |
|---|---|
| 客户理解页 | 快速看懂 OTC USD 大宗交易是什么 |
| BD 转化页 | 帮助销售推进注册、KYC、首单 |
| 流程说明页 | 买币/卖币流程清晰可循 |
| 物料入口 | FAQ、流程图、表单的统一源 |

### 亮色模式

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#0052FF` | 主品牌色：按钮、链接、强调元素 |
| `--brand-dark` | `#003ECC` | 品牌色深色态：hover 状态 |
| `--brand-soft` | `#EEF4FF` | 品牌色浅色态：选中态背景、标签 |
| `--bg` | `#FFFFFF` | 页面背景 |
| `--bg-soft` | `#F6F8FB` | 次级背景：卡片替代背景、角色框 |
| `--line` | `#E8ECF2` | 边框色：卡片边框、分割线 |
| `--text` | `#14181F` | 主文字色：标题、正文 |
| `--text2` | `#5A6272` | 辅助文字色：副标题、说明 |
| `--text3` | `#8A93A6` | 弱化文字色：风险提示、辅助信息 |
| `--shadow` | `0 2px 12px rgba(20,30,60,.05)` | 默认阴影 |
| `--shadow-hover` | `0 10px 32px rgba(0,82,255,.10)` | 悬停阴影（带品牌色） |

### 深色模式

| Token | 值 |
|---|---|
| `--brand` | `#3E8EFF`（亮色 +6 度） |
| `--bg` | `#060708` |
| `--text` | `#EDEFF3` |
| `--text2` | `#A2A8B3` |
| `--line` | `rgba(255,255,255,.1)` |

### 色彩使用原则

- **蓝色为核心主色**，不做大面积渐变
- 警告/注意信息使用黄色系（`#FFF8EC` 背景 + `#F5E3B8` 边框）
- 成功状态使用绿色系（`#EAF9F0` 背景 + `#16A34A` 文字）
- 错误状态使用红色系（`#E5484D`）
- 卡片背景统一使用 `rgba(255,255,255,.62)` + `backdrop-filter:blur(14px)` 毛玻璃效果
- 深色模式下卡片背景改为 `rgba(22,24,29,.6)`

## 6. Motion Rules

### 动效类型

| 动效 | 实现 | 参数 | 用途 |
|---|---|---|---|
| 浮现 Reveal | CSS transition | 0.72s cubic-bezier(.16,1,.3,1) | 页面滚动元素渐入 |
| 卡片悬停 | CSS transition | 0.3s cubic-bezier(.16,1,.3,1) | ↑-3px + shadow-hover |
| 箭头滑入 | CSS transition | 0.3s transform | CTA 箭头向右滑出 4px |
| 手风琴展开 | CSS transition | 0.35s / 0.4s cubic-bezier(.16,1,.3,1) | FAQ 展开/折叠 |
| 下滑引导 | CSS keyframes | 2.4s ease-in-out infinite | 滚动提示浮动 |
| 弹窗弹出 | CSS keyframes | 0.35s cubic-bezier(.16,1,.3,1) | 表单弹窗出现 |
| 导航栏阴影 | CSS transition | 0.3s | 滚动后阴影加深 |
| 步骤滑入 | CSS keyframes | 0.38-0.42s cubic-bezier(.16,1,.3,1) | 步骤方向切换 |

### 动效设计原则

- **统一缓动函数**：全部使用 `cubic-bezier(.16, 1, .3, 1)`（"Sera Ease"）
  - 起始快（0.16 → 迅速响应）
  - 结束缓（1, .3 → 自然减速）
  - 既不过度弹跳，也不显得拖沓
- 悬停动效克制：仅上移 3px + 阴影加深，不做夸张旋转/缩放
- 展开动效使用 max-height transition，不依赖 JS 计算高度
- 浮现动画总是从下往上 + 淡入（translateY 26px + opacity 0 → 1）
- 深色模式下保持与亮色模式一致的动效参数

## 7. Conversion Patterns

### 转化路径

```
路径 A（客户自助）
Hero → 选择买币/卖币 → 子页流程 → 提交需求 → TG 联系

路径 B（机构合作）
Hero → 机构合作入口 → 机构介绍 → 提交合作需求 → 表单 → TG 联系

路径 C（FAQ 转化）
FAQ → 仍有疑问 → TG 联系
```

### 转化设计模式

| 模式 | 说明 |
|---|---|
| 首屏双 CTA | 买币/卖币两个入口卡片并排，客户立即选择方向 |
| 渐进式表单 | 三步分步表单，降低填写压力 |
| 弹窗表单 | 不跳转页面，保持上下文 |
| TG 兜底 | 所有转化失败的场景提供人工联系入口 |
| 信任前置 | KYC 提示在首屏底部出现，降低客户疑虑 |
| FAQ 拦截 | 常见问题在转化前解决，减少无效咨询 |

### 表单设计原则

- 最小字段集：首屏仅收 3 类字段（客户类型 + 意向 + 联系方式）
- 分步收集：先收关键字段，再收补充字段
- 状态明确：默认态 → 填写中 → 校验失败 → 提交中 → 成功/失败
- 不锁死必须提交：提供"资料不齐，TG 联系"的逃生出口

## 8. 深色模式设计

### 转换规则

| 转换 | 亮色 → 深色 |
|---|---|
| 品牌色 | `#0052FF` → `#3E8EFF`（+6 亮度） |
| 背景 | `#FFFFFF` → `#060708` |
| 文字 | `#14181F` → `#EDEFF3` |
| 边框 | `#E8ECF2` → `rgba(255,255,255,.1)` |
| 卡片背景 | `rgba(255,255,255,.62)` → `rgba(22,24,29,.6)` |
| 阴影 | 浅色阴影 → 深色阴影（`rgba(0,0,0,.35)`） |
| 毛玻璃 | 浅色玻璃 → 深色玻璃 |

### 设计原则
- 深色模式不是简单的取反，而是独立设计色彩映射
- 品牌色适度提高亮度以保证在深色背景上的可读性
- 保持毛玻璃效果，但背景色调整
- 所有卡片 hover 状态在深色模式下使用新品牌色阴影

## 9. Key Learnings

### 成功的决策
1. **首屏双入口卡片**：买币/卖币方向明确，降低客户认知负担
2. **毛玻璃卡片**：统一视觉语言，提升 premium 感
3. **统一缓动函数**：所有动效使用同一曲线，体验一致
4. **深色模式独立设计**：不是取反而是重新映射，体验更好
5. **FAQ 双列布局**：折叠 + 更多展开，信息密度可控

### 需要改进的方面
1. 移动端导航栏可考虑增加汉堡菜单
2. 表单成功率可增加更多验证反馈
3. 机构版内容与客户版共享设计系统但独立实现，可考虑统一

### 新增设计规则（v1.0 → 后续版本参考）
- 金融产品页面首屏必须展示"交易方向选择"
- 所有表单必须提供"人工联系"逃生出口
- 信任标识（KYC/合规提示）必须在首屏可见
