## 1. 页面结构分析

### 信息架构
```text
A. 执行摘要（PIP 健康度全景）
B. KPI 概览（6 大绩效目标实时进度）
C. 任务倒计时（秒级实时刷新）
D. 主线任务进度（5 条绩效主线）
E. 工作 Pipeline（全部工作项按状态分组）
F. 主线任务时间推进图（Gantt 风格）
G. 任务关系树（依赖与包含关系）
H. 每周总结与复盘
I. 资料访问中心（关键资料入口）
```

### 布局规则
- 单列纵向滚动（非多列 Dashboard）
- 每个模块用字母前缀（A-I）标识
- 模块间用分隔线区分
- 卡片式内容容器

## 2. KPI 设计模式

### KPI 卡片结构
```
┌──────────────────────────────────┐
│ 机构注册                         │
│ 待启动                           │
│ 0/6  家 · 0%                     │
│ ████████░░░░░░░░░░░░ 0%         │
│ 目标：≥6家                       │
│ 下一步：从 CRM 中筛选线索        │
└──────────────────────────────────┘
```

### 状态标签系统
| 状态 | 含义 |
|---|---|
| 待启动 | 未开始 |
| 进行中 | 推进中 |
| 已完成 | 已完成 |
| 已阻塞 | 遇到阻碍 |

### KPI 设计规则
- 每个 KPI 包含：标题 + 状态标签 + 数值进度 + 进度条 + 目标值 + 下一步动作
- 进度条使用百分比填充
- 数值同时显示当前值和目标值（0/6）
- 状态标签使用颜色区分（已完成=绿色，待启动=灰色，阻塞=红色）

## 3. Dashboard 布局规则

### 3.1 执行摘要
```
┌──────────────────────────────────────┐
│ 执行摘要                             │
│                                      │
│ 总体进度    49%     ████░░░░         │
│ 本周完成    2/9                      │
│ 当前阻塞    需协助 3                 │
│ 下一里程碑  首单交易测试 · 待启动    │
└──────────────────────────────────────┘
```
- 关键指标水平排列
- 每个指标带简短说明文字
- 下一步建议使用不同颜色高亮

### 3.2 任务倒计时
```
┌──────────────────────────────────────┐
│ 任务倒计时                           │
│                                      │
│ T-0004  待启动                       │
│ 配合首单测试                         │
│ 已逾期 26天 10:42:12                 │
│ ★★★★                               │
│ 下一步：配合静格完成首单测试         │
└──────────────────────────────────────┘
```
- 优先级使用星标（★）
- 倒计时实时刷新
- 逾期显示红色
- 任务编号 T-XXXX 标识

### 3.3 工作 Pipeline
- 按状态分组（待启动 / 进行中 / 已完成 / 已阻塞）
- 每个工作项包含：标题 + 截止日期 + 所属主线 + 下一步动作
- 截止日期优先显示

| KPICard | 绩效指标展示 | 标题 + 状态 + 数值 + 进度条 + 目标 + 下一步 |
| SummaryCard | 执行摘要 | 关键指标水平排列 |
| CountdownCard | 任务倒计时 | 编号 + 标题 + 倒计时 + 优先级 + 下一步 |

| TimelineView | 时间推进图 | Gantt 风格时间线 |
| ResourceCard | 资料入口 | 标题 + 类型 + 描述 + 状态 + 更新日期 |

## 6. 与 Landing Page 的设计差异

| 维度 | Landing Page | Dashboard |
|---|---|---|
| 目标 | 转化客户 | 管理运营 |
| 信息密度 | 低（清晰展示） | 高（信息密集） |
| 视觉焦点 | 品牌 + CTA | 数据 + 状态 |
| 动效 | 浮现 + 悬停 | 倒计时实时刷新 |
| 色彩 | 品牌蓝为主 | 状态色为主 |
| 字体 | 大标题为主 | 小字号 + 数据密集 |
| 布局 | 对称居中 | 单列纵向 |

## 7. Dashboard 设计原则

1. **信息密度优先**：Dashboard 的核心是信息效率，不是美观
2. **状态一目了然**：每个项目第一时间展示状态
3. **数据驱动**：所有指标可量化、可追踪
4. **下一步明确**：每个模块底部展示下一步动作
5. **实时性**：倒计时秒级刷新，进度即时可见
6. **分组清晰**：按状态/主线/优先级分组，降低认知负荷
