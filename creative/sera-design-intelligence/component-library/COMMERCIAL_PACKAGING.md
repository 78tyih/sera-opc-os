# Sera Component Library — Commercial Packaging

## Product Principle

客户买的不是“13 个 HTML 卡片”。

客户真正购买的是：

> 已经在真实项目中验证过的设计决策 + 可运行组件 + 可组合模板 + Agent 使用规则。

因此商业包装必须从代码文件升级为“可交付的设计能力”。

## 1. Product Ladder

### Free — Component Gallery

目的：获客与建立信任。

内容：
- 在线 Component Gallery
- 组件用途说明
- 少量 Demo
- 设计思想文章

不提供：
- 完整源码
- Agent Skill
- Template Pack

### Starter — Component Pack

适合：独立开发者、Designer、AI Builder。

内容：
- 组件源码
- HTML / CSS reference
- Design Tokens
- Light / Dark
- Responsive rules
- Sample data
- Component Spec

### Pro — Template Pack

适合：创业者、Agency、Product Team。

内容：
- Starter 全部内容
- 完整 Template
- 多个页面组合
- 替换品牌 / 文案指南
- Demo Data
- Deployment guide

首批：
- Regulated Deal Desk
- Execution Command Center

### AI — Skill Pack

适合：Codex / Claude Code / Cursor / Trae / WorkBuddy 用户。

内容：
- Template Pack
- SKILL.md
- Component Registry
- Style Router rules
- Example prompts
- Review checklist

目标体验：

> 用户不需要自己拼组件，只需要描述产品与目标，Agent 自动选择 Style + Component + Template。

### Studio — Solution Pack

适合：小团队、Agency、企业创新团队。

内容：

```text
Design System
+ Component Library
+ Template Library
+ Agent Skill
+ Sample Data Schema
+ Integration Guide
+ Deployment Guide
+ Commercial License
```

## 3. Pricing Logic

不要按“文件数量”定价。

定价维度应为：

1. **Reuse depth** — 单组件 / 完整模板 / 完整解决方案
2. **Automation level** — 手动套模板 / Agent 自动生成
3. **License scope** — 个人 / 商业 / Agency / Enterprise
4. **Support level** — 文档 / 更新 / 定制 / 集成

可测试的价格梯度：

```text
Free Gallery
→ Component Pack
→ Template Pack
→ AI Skill Pack
→ Studio / Enterprise
```

具体价格应通过 Smoke Test / Waitlist / Early Access 验证，不在设计资产层硬编码。

```text

```

### Sera Design Asset

```text
Executive Summary Card
KPI Metric Card
Status Pipeline Board
High-Trust Hero
Process Stepper
```

前者提供 primitive。
后者提供 **业务问题的设计答案**。

```text

→ Evidence

→ Components
```
