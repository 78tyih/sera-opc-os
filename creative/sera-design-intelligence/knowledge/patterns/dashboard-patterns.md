# UI Pattern: Dashboard

> 知识类型：ui-pattern
> 版本：1.0.0
> 适用：运营 Dashboard / 管理后台 / KPI 监控

---

## 模式概述

Dashboard 的设计目标是：让用户快速理解当前状态，发现异常，并知道下一步做什么。

---

## 模式变体

### 1. 执行摘要型

```
适用：管理层 / 项目整体状态

结构：
┌──────────────────────────────────────┐
│ 执行摘要                              │
│                                      │
│  总体进度    49%     ████░░░░         │
│  本周完成    2/9                      │
│  当前阻塞    需协助 3                 │
│  下一里程碑  首单交易测试 · 待启动    │
└──────────────────────────────────────┘

特点：
- 关键指标水平排列
- 每个指标带简短说明
- 下一步建议高亮
```

### 2. KPI 矩阵型

```
适用：团队 / 多指标监控

结构：
┌──────────┐  ┌──────────┐  ┌──────────┐
│ KPI 1    │  │ KPI 2    │  │ KPI 3    │
│ 状态标签  │  │ 状态标签  │  │ 状态标签  │
│ 0/6      │  │ 12/15    │  │ 8/8      │
│ ██░░░░░  │  │ █████░░  │  │ ███████  │
│ 下一步…   │  │ 下一步…   │  │ 下一步…   │
└──────────┘  └──────────┘  └──────────┘
│ KPI 4    │  │ KPI 5    │  │ KPI 6    │
│ ...      │  │ ...      │  │ ...      │
└──────────┘  └──────────┘  └──────────┘
```

### 3. Pipeline 型

```
适用：流程管理 / 任务跟踪

结构：
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ 待启动    │  │ 进行中    │  │ 已完成    │  │ 已阻塞    │
│          │  │          │  │          │  │          │
│ 任务1    │  │ 任务3    │  │ 任务5    │  │ 任务7    │
│ 任务2    │  │ 任务4    │  │ 任务6    │  │          │
│          │  │          │  │          │  │          │
└──────────┘  └──────────┘  └──────────┘  └──────────┘
```

## Dashboard 设计规则

### 1. 状态系统

```
🟢 已完成 — 绿色 #16A34A / 背景 #EAF9F0
🔵 进行中 — 蓝色 #0052FF / 背景 #EEF4FF
⚪ 待启动 — 灰色 #8A93A6 / 背景 #F6F8FB
🔴 已阻塞 — 红色 #E5484D / 背景 #FFF0F0
```

### 2. 数据展示

```
KPI 卡片标准结构：
- 标题（14px 600 text2）
- 状态标签（12px 600 badge）
- 数值（当前值 / 目标值 · 百分比）
- 进度条（状态色填充）
- 下一步动作（13px 500）
```

### 3. 信息密度

```
Dashboard 的信息密度 > Landing Page。
- 字号缩小 1-2px
- 卡片内边距 20px（vs Landing 28px）
- 间距压缩
- 更多数据在同一视口
```

## 检查清单

- [ ] 每个模块是否第一时间展示状态？
- [ ] 数据是否可量化、可追踪？
- [ ] 每个模块底部是否有"下一步"动作？
- [ ] 关键数字是否使用了强调样式？
- [ ] 状态标签是否颜色编码？
- [ ] 是否有实时数据刷新机制？
