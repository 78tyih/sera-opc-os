# UI Pattern: Hero Section

> 知识类型：ui-pattern
> 版本：1.0.0
> 适用：Landing Page 首屏

---

## 模式概述

Hero 是用户看到的第一屏，决定了用户是否继续浏览。设计目标是 3 秒内传递价值主张。

---

## 模式变体

### 1. 金融信任型

```
适用：金融 / 大额交易 / 机构服务

结构：
┌──────────────────────────────────┐
│  大标题 64px 800                  │
│  副标题 17px                      │
│  ┌──────────┐  ┌──────────┐     │
│  │ CTA 1    │  │ CTA 2    │     │
│  └──────────┘  └──────────┘     │
│  KYC / 合规提示                   │
│  下滑引导                          │
└──────────────────────────────────┘

特点：
- 双入口选择（降低决策负担）
- 信任信号在首屏底部
- 无复杂图表 / 动画
```

### 2. SaaS 产品型

```
适用：SaaS / 工具 / 平台

结构：
┌──────────────────────────────────┐
│  大标题 + 产品截图                │
│  副标题                          │
│  CTA + 免费试用                   │
│  ┌──┐ ┌──┐ ┌──┐                 │
│  │  │ │  │ │  │ 信任标识          │
│  └──┘ └──┘ └──┘                 │
└──────────────────────────────────┘

特点：
- 产品截图 / Demo 占据右侧 50%
- 免费试用降低行动门槛
- 客户 Logo 墙建立社会证明
```

### 3. AI 产品型

```
适用：AI / 智能 / 机器学习

结构：
┌──────────────────────────────────┐
│  AI 能力主标题                     │
│  副标题                          │
│  ┌──────────────────────┐       │
│  │  Demo 区域            │       │
│  │  输入 → 输出           │       │
│  └──────────────────────┘       │
│  CTA                            │
└──────────────────────────────────┘

特点：
- Demo 是核心转化工具
- 展示真实输入输出
- 技术可信度说明
```

---

## 模式选择指南

| 产品类型 | 推荐模式 | 原因 |
|---|---|---|
| 金融 / 大额交易 | 金融信任型 | 信任比兴奋更重要 |
| SaaS / 工具 | SaaS 产品型 | 展示产品价值 |
| AI / 智能 | AI 产品型 | Demo 说服力最强 |
| 内容平台 | 金融信任型（适配） | 内容质量信任 |
| 电商 | SaaS 产品型（适配） | 产品展示优先 |

## Hero 设计检查清单

- [ ] 3 秒内能否理解业务是什么？
- [ ] 是否有明确的 CTA？
- [ ] 信任信号是否可见？
- [ ] 移动端是否适配（字体 clamp / 布局降级）？
- [ ] 是否有滚动引导？（下滑箭头 / 提示）
- [ ] 深色模式是否正常？
