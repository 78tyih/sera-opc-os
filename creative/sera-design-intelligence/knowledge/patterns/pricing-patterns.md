# UI Pattern: Pricing Section

> 知识类型：ui-pattern
> 版本：1.0.0
> 适用：SaaS 定价 / 套餐选择 / 会员方案

---

## 模式概述

定价页的设计目标是：让用户快速理解价值差异，选择适合自己的方案，并降低决策焦虑。

---

## 模式变体

### 1. 三列标准型

```
适用：SaaS / 订阅 / 会员

结构：
┌──────────┐ ┌──────────┐ ┌──────────┐
│  Basic    │ │  Pro ⭐  │ │  Enterprise│
│           │ │          │ │           │
│  $9/mo    │ │  $29/mo  │ │  定制     │
│           │ │          │ │           │
│  ✓ 功能1  │ │  ✓ 功能1 │ │  ✓ 全部   │
│  ✓ 功能2  │ │  ✓ 功能2 │ │  + 定制   │
│           │ │  ✓ 功能3 │ │  + 支持   │
│           │ │  ✓ 功能4 │ │           │
│ [CTA]     │ │ [CTA]    │ │ [CTA]    │
└──────────┘ └──────────┘ └──────────┘

特点：
- 推荐方案（Pro）高亮（边框 / 标签）
- 功能对比清晰
- 价格锚定（中间方案最推荐）
```

### 2. 双列对比型

```
适用：简单二选一 / 个人 vs 团队

结构：
┌──────────────┐  ┌──────────────┐
│  Personal     │  │  Team        │
│               │  │              │
│  免费 / 基础  │  │ 付费 / 高级  │
│               │  │              │
│  ✓ 基本功能   │  │  ✓ 全部功能  │
│               │  │  ✓ 协作功能  │
│               │  │  ✓ 管理功能  │
│               │  │              │
│  [免费使用]   │  │ [开始试用]   │
└──────────────┘  └──────────────┘
```

## 定价设计规则

### 1. 价格展示

```
- 价格数字：大号 + 粗体（32px 700）
- 周期说明：小号 + 辅助色（14px text2）
- 货币符号：小号 + 上标（$ 14px → 32px）
```

### 2. 方案高亮

```
推荐方案视觉差异：
- 品牌色边框（2px）
- "最受欢迎"标签
- 卡片阴影更深
- 按钮与其他方案颜色不同
```

### 3. 功能列表

```
- 有：绿色 ✓ 图标
- 无：灰色 - 或 ○
- 关键差异：加粗 / 高亮
- 自定义：标注"定制"
```

---

## 定价心理学

### 锚定效应

```
展示三个方案，中间方案通常是最推荐的选择。

用户会对比三个方案，而不是评估单个方案的价值。
```

### 降低决策焦虑

```
- 月付 → 年付（省 XX%）
- 免费试用（无风险）
- 随时取消（降低承诺感）
```

## 检查清单

- [ ] 是否有 3 个方案（含锚定方案）？
- [ ] 推荐方案是否视觉高亮？
- [ ] 价格数字是否足够大？
- [ ] 功能对比是否清晰？
- [ ] 是否有"免费试用"选项？
- [ ] 移动端是否可用（横向滚动 / 降级）？
