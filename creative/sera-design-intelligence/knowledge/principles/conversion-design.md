# Design Principle: Conversion-Driven Design

> 知识类型：design-principle
> 版本：1.0.0
> 适用：Landing Page / 产品页 / 注册页

---

## 核心原则

**页面不是为了好看，是为了让用户做某个动作。**

每个设计决策都应该服务于转化目标。

---

## 转化漏斗

```
Attention（注意）     → 0-3s：Hero 吸引注意力
    ↓
Understanding（理解） → 3-10s：价值主张清晰
    ↓
Trust（信任）        → 10-30s：建立信任
    ↓
Action（行动）       → 30s+：CTA 转化
```

---

## 转化设计模式

### 1. 首屏转化

```
首屏必须包含：
- 价值主张（What）
- 目标用户匹配（Who）
- 行动入口（How）
```

### 2. 渐进式承诺

```
不要求用户一次性完成全部动作。

步骤：
1. 点击 CTA（低承诺）
2. 填写基本信息（中承诺）
3. 提交需求（高承诺）
```

### 3. 信任前置

```
信任信号必须在转化前展示：
- 客户数量 / 交易量
- 合规认证
- 品牌背书
- 安全保障
```

### 4. 逃生出口

```
每个转化节点提供替代路径：
- "资料不齐？联系人工"
- "不确定？先了解 FAQ"
- "有问题？在线咨询"
```

---

## CTA 设计规则

### 位置

| 位置 | 转化率 | 说明 |
|---|---|---|
| 首屏 | 最高 | 用户注意力最集中 |
| Section 结尾 | 中 | 用户读完内容后 |
| 页底 | 低 | 用户已滚动到底 |

### 文案

```
高转化：开始交易 / 立即申请 / 免费试用
中转化：了解更多 / 查看详情 / 联系专家
低转化：提交 / 确认 / 下一步
```

### 样式

```
主 CTA：品牌色填充 + 白色文字 + 箭头
次 CTA：边框样式 / 文字链接
辅助 CTA：text2 色文字链接
```

---

## 转化检查清单

- [ ] 首屏 3 秒内是否有 CTA？
- [ ] 每个 Section 是否有"下一步"动作引导？
- [ ] 表单是否最小字段集？（不超过 3 个）
- [ ] 是否有逃生出口？
- [ ] 信任信号是否在转化前可见？
- [ ] CTA 文案是否使用行动导向词汇？
