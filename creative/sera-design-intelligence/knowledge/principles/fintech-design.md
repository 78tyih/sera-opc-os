# Design Principle: FinTech Product Design

> 知识类型：design-principle
> 版本：1.0.0
> 适用：金融产品 / 交易平台 / 投资服务

---

## 核心原则

**金融产品的设计核心是信任，不是功能。**

用户在使用金融产品前，必须首先相信：
1. 平台安全（资金安全）
2. 业务合规（合法合规）
3. 服务专业（团队可信）

---

## 金融产品设计特性

### 1. 信任即转化

| 信任信号 | 设计方式 | 优先级 |
|---|---|---|
| 合规认证 | 首屏 Logo / 页脚 | P0 |
| 交易量/用户数 | 数据卡片 | P0 |
| 安全保障 | 安全图标 + 说明 | P1 |
| 合作机构 | Logo 墙 | P1 |
| 客户案例 | 案例卡片 | P2 |

### 2. 降低认知负担

金融产品天然复杂。设计必须降低理解成本：

```
"OTC 大宗交易" → "大额买币 / 大额卖币"
"RFQ 报价机制" → "询价 → 报价 → 成交"
"KYC 认证"    → "身份认证 → 交易权限"
```

### 3. 合规即设计

```
- 风险提示必须在页脚可见（12px min）
- 不出现"保证收益""保本"等误导词
- 不展示后台合作方、银行内部链路
- 不承诺具体交易结果或到账时间
```

## 金融产品色彩策略

### 信任色板

```
主色：蓝色系（#0052FF）→ 专业、安全、可信
辅色：深色系（#14181F）→ 稳重、严肃
强调色：金色/绿色 → 资产、收益、安全
```

### 避免的色彩

```
❌ 红色作为主色 → 亏损、风险、警告
❌ 大面积橙色 → 促销感、非专业
❌ 霓虹色 → 不安全、不可靠
```

---

## 金融产品布局策略

### 信息展示顺序

1. 安全与合规（建立信任）
2. 业务价值（解决什么问题）
3. 交易流程（怎么操作）
4. 费率与条件（透明）
5. FAQ（常见问题）
6. 联系（转化）

### 数据展示

```
大额数据强调：
$100M+     → 48px 700
Liquidity → 14px text2

使用大号数字 + 小号标签的组合
```

- [ ] 信任信号是否在首屏可见？

- [ ] 数据展示是否使用了强调样式？
- [ ] 复杂金融术语是否被解释？
- [ ] 合规信息是否在合理位置展示？
