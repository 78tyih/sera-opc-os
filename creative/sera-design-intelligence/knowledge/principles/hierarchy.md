# Design Principle: Visual Hierarchy

> 知识类型：design-principle
> 版本：1.0.0
> 适用：所有页面设计

---

## 核心原则

**用户第一眼看到什么，决定了他们是否继续看下去。**

视觉层级的目的是用设计引导视线，而非用文案堆砌。

---

## 层级规则

### 1. 三秒法则

用户 3 秒内应完成：
1. 知道这是什么业务（Hero 标题）
2. 知道是否与自己相关（副标题）
3. 知道下一步做什么（CTA）

### 2. F 型视觉动线

```
① 大标题（第一焦点）
    ↓
② 副标题 / CTA（第二焦点）
    ↓
③ 内容卡片（第三焦点）
    ↓
④ 辅助信息（第四焦点）
```

### 3. 字号对比原则

| 关系 | 字号差 | 效果 |
|---|---|---|
| Hero 标题 → 卡片标题 | 64px → 19px | 视觉跳跃明显，瞬间建立层级 |
| 卡片标题 → 正文 | 19px → 15px | 清晰区分标题与内容 |
| 正文 → 辅助文字 | 15px → 13px | 次要信息自然后退 |

### 4. 间距即层级

- 越重要的元素，上方留白越多
- 相关元素间距小（8-16px），不相关元素间距大（40-84px）
- Section 间距 84px 建立视觉"段落"

---

## 常见错误

| 错误 | 后果 | 修复 |
|---|---|---|
| 标题不够大 | 用户在首屏找不到重点 | 使用 clamp(44px, 6vw, 64px) |
| 所有元素一样大 | 页面没有视觉焦点 | 建立 3-4 级字号系统 |
| 间距过于均匀 | 内容没有分组感 | 使用 8px 基数间距系统 |
| 色彩过于平均 | 强调元素不突出 | 品牌色仅用于交互元素 |

---

## 检查清单

- [ ] 首屏 3 秒内能否理解业务是什么？
- [ ] 标题层级是否足够明显？（64px → 19px → 15px）
- [ ] 是否有 3 个以上视觉焦点？（过多则无焦点）
- [ ] CTA 是否在视觉上突出？
- [ ] 间距是否区分了内容分组？
