# Design Psychology: Conversion Psychology

> 知识类型：design-psychology
> 版本：1.0.0
> 适用：Landing Page / 注册页 / 购买页

---

## 核心机制

**用户不是理性决策者。设计必须顺应认知偏见，而非对抗它。**

---

## 认知偏见与设计应用

### 1. 锚定效应

```
原理：用户依赖第一个信息做后续判断。

设计应用：
- 定价页展示三个方案，中间方案为推荐
- 先展示"原价"，再展示"现价"
- 先展示大额数字，再展示小额
```

### 2. 损失厌恶

```
原理：失去的痛苦 > 获得的快乐（约 2:1）。

设计应用：
- "限时优惠"（不行动会失去）
- "仅剩 X 个名额"（稀缺性）
- "免费试用，随时取消"（0 风险）
```

### 3. 社会证明

```
原理：用户倾向于跟随他人行为。

设计应用：
- "已有 10,000+ 用户"
- 客户评价（带头像）
- 知名客户 Logo 墙
- 实时购买/注册通知
```

### 4. 承诺一致性

```
原理：用户倾向于保持一致的行为模式。

设计应用：
- 渐进式表单（首先做出小承诺）
- 免费试用 → 自动转为付费
- 先点"了解更多" → 再展示 CTA
```

### 5. 峰终定律

```
原理：用户对体验的评价基于"最高点"和"结束点"。

设计应用：
- 注册流程中设置"惊喜时刻"
- 结束页面展示成功状态
- 最后一步给予正面反馈
```

## 转化文案心理学

### 降低行动门槛

```
"开始试用" > "立即购买"
"了解详情"  > "马上注册"
"免费体验"  > "付费订阅"
```

### 正面框架

```
"95% 成功率" > "5% 失败率"
"已服务 10 万用户" > "注册用户 10 万"
"30 天免费" > "30 天后付费"
```

## 检查清单

- [ ] 是否使用了锚定效应？（三个方案）
- [ ] 是否有稀缺性/紧迫感信号？
- [ ] 是否有社会证明（数据/客户）？
- [ ] 是否使用了渐进式承诺？
- [ ] 转化路径是否从低承诺到高承诺？
- [ ] 文案是否使用正面框架？
