# Design Psychology: Trust in Design

> 知识类型：design-psychology
> 版本：1.0.0
> 适用：金融 / 大额交易 / 高价值服务

---

## 核心机制

**信任是金融产品转化的前置条件。**

用户在使用金融产品前，潜意识中会评估三个问题：
1. 这个平台安全吗？
2. 这个团队专业吗？
3. 如果我出问题，有人负责吗？

---

## 信任设计模式

### 1. 权威信号

```
设计方式：
- 合规认证 Logo（FCA / MSB / 等）
- 合作机构 Logo 墙
- 行业奖项 / 媒体报道
- 团队介绍（真人照片 + 履历）

原理：
用户倾向于相信权威机构认可的平台。
```

### 2. 社会证明

```
设计方式：
- 用户数量（"100,000+ 用户"）
- 交易量（"$100M+ 月交易量"）
- 客户评价 / 案例
- 实时交易数据（如可行）

原理：
用户倾向于跟随其他人的选择。
```

### 3. 透明度

```
设计方式：
- 费率公开
- 流程可视化
- 风险提示明确
- 联系信息真实

原理：
透明度降低不确定性，不确定性降低信任。
```

### 4. 安全符号

```
设计方式：
- 安全锁图标
- SSL 证书展示
- 资金托管说明
- 隐私政策链接

原理：
安全符号触发用户的"安全"联想。
```

---

## 信任信号的视觉层级

```
首屏（最高优先级）：
- 合规认证 Logo
- 用户 / 交易量数据

中间（中等优先级）：
- 合作 Logo 墙
- 安全说明

页脚（最低优先级）：
- 风险提示
- 隐私政策
```

---

## 信任设计检查清单

- [ ] 首屏是否有合规/安全信号？
- [ ] 是否有可验证的数据（用户量/交易量）？
- [ ] 费率是否透明可见？
- [ ] 联系信息是否真实可查？
- [ ] 风险提示是否在合理位置？
- [ ] 是否有第三方认证/背书？
