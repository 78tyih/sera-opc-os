# Design Psychology: User Attention Management

> 知识类型：design-psychology
> 版本：1.0.0
> 适用：所有页面设计

---

## 核心机制

**用户的注意力是稀缺资源。设计的目标是引导注意力到正确的位置，而非分散它。**

---

## 注意力模型

### 1. 3 秒法则

```
用户决定是否继续浏览的时间：3 秒。

在这 3 秒内，用户完成：
1. 扫描页面整体（Gestalt 整体感知）
2. 定位最大/最突出的元素（视觉焦点）
3. 判断是否与自己相关（内容匹配）

设计含义：
- 首屏必须有明确的视觉焦点
- 价值主张必须在 3 秒内可读
- 不分散注意力的装饰
```

### 2. F 型扫描模式

```
用户的阅读模式：
┌──────────────────────────────────┐
│ ① 第一行标题（完整阅读）          │  ← F 第一横
│ ② 第二段开头（部分阅读）          │  ← F 第二横
│ ③ 下方内容（快速扫描）            │  ← F 竖线
└──────────────────────────────────┘

设计含义：
- 最重要的信息放在左上角
- 标题使用大号 + 粗体
- 关键信息放在段落开头
```

### 3. 视觉重量

```
元素吸引注意力的能力不同：

高视觉重量：
- 大号文字（64px > 16px）
- 高对比度（品牌色 > 灰色）
- 动态元素（动画 > 静态）
- 人脸 / 眼睛（生物本能）

低视觉重量：
- 小号文字
- 低对比度
- 常规内容
- 重复模式
```

## 注意力管理策略

### 1. 减少选择

```
希克定律：选择越多，决策时间越长。

设计应用：
- Hero 最多 2 个 CTA
- 表单最多 3 个字段/步
- 导航最多 5 个链接
- 定价最多 3 个方案
```

### 2. 引导视线

```
设计元素引导视线流动：
- 箭头 / 线条 → 指向 CTA
- 人物视线 → 看向 CTA
- 大小对比 → 大→小流动
- 色彩对比 → 品牌色引导
```

### 3. 减少认知负荷

```
- 每页只讲一件事
- 每个 Section 只有一个核心信息
- 使用图标替代文字说明
- 避免专业术语（或解释）
- 信息分组（7±2 法则）
```

## 注意力陷阱

| 陷阱 | 后果 | 修复 |
|---|---|---|
| 过多动画 | 用户无法聚焦内容 | 动效克制，仅用于引导 |
| 过多色彩 | 用户不知道看哪里 | 品牌色仅用于交互元素 |
| 过多 CTA | 用户不做任何选择 | 每种意图只给一个 CTA |
| 信息过载 | 用户跳过内容 | 每 Section 只讲一件事 |
| 装饰过度 | 分散注意力 | 装饰服务于内容 |

## 检查清单

- [ ] 首屏是否有明确的视觉焦点？
- [ ] 3 秒内能否理解核心价值？
- [ ] 是否有 2 个以上同等突出的元素？（过多则无焦点）
- [ ] 页面是否使用了 F 型布局？
- [ ] 每个 Section 是否只有一个核心信息？
- [ ] CTA 是否在视觉上最突出？
