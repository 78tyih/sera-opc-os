# Design Iteration Log

> 设计迭代日志 — 记录每次设计优化与决策依据

## 格式

每次迭代记录：

```yaml
iteration: <编号>
date: <日期>
product: <产品>
trigger: <触发原因 — 数据反馈/用户反馈/设计评审>
change: <变更描述>
rationale: <决策依据>
result: <结果>
new_rule: <是否生成新设计规则>
```
