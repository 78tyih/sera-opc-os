# UI Pattern: Hero Section

> 知识类型：pattern-library
> 版本：1.0.0
> 模式库分类：hero
> 适用：Landing Page 首屏、品牌首页

---

## 模式概述

Hero 是用户看到的第一屏，决定了用户是否继续浏览。设计目标是 3 秒内传递价值主张。本库收录了四种核心 Hero 模式，每种模式针对不同的产品类型和用户心理。

---

## 模式变体

### 1. Trust Hero（信任至上型）

**适用场景**：金融、大额交易、机构服务、B2B 企业服务

**结构布局**：
```
┌──────────────────────────────────┐
│  大标题 64px 800                  │
│  副标题 17px（价值主张）           │
│  ┌──────────┐  ┌──────────┐     │
│  │ CTA 1    │  │ CTA 2    │     │
│  └──────────┘  └──────────┘     │
│  KYC / 合规提示                   │
│  下滑引导                          │
└──────────────────────────────────┘
```

**关键元素**：
- 双入口 CTA 降低决策负担
- 信任信号在首屏底部（合规、认证、安全标识）
- 无复杂图表或动画，保持庄重感
- 保守的留白和字体选择

**视觉特征**：
- 深色或中性色背景，传递专业感
- 字体权重较高（800+），强调确定性
- 色彩克制，以品牌色点缀

**参考案例**：Bloomberg Terminal、Coinbase 企业页

---

### 2. Product Hero（产品展示型）

**适用场景**：SaaS、工具、平台、开发者工具

**结构布局**：
```
┌──────────────────────────────────┐
│  大标题 + 产品截图                │
│  副标题                          │
│  CTA + 免费试用                   │
│  ┌──┐ ┌──┐ ┌──┐                 │
│  │  │ │  │ │  │ 客户 Logo 墙     │
│  └──┘ └──┘ └──┘                 │
└──────────────────────────────────┘
```

**关键元素**：
- 产品截图 / Demo 占据右侧 50% 以上空间
- "免费试用"降低行动门槛
- 客户 Logo 墙建立社会证明
- 左侧文案，右侧视觉的经典布局

**视觉特征**：
- 亮色背景为主，展示产品界面
- 产品截图带圆角和阴影，突出质感
- 字体现代、清爽

**参考案例**：Linear、Notion、Vercel

---

### 3. AI Hero（AI 能力演示型）

**适用场景**：AI 产品、智能工具、机器学习平台

**结构布局**：
```
┌──────────────────────────────────┐
│  AI 能力主标题                     │
│  副标题                          │
│  ┌──────────────────────┐       │
│  │  Demo 区域            │       │
│  │  输入 → 输出           │       │
│  └──────────────────────┘       │
│  CTA                            │
└──────────────────────────────────┘
```

**关键元素**：
- Demo 是核心转化工具，展示真实输入输出
- 技术可信度说明（模型名称、性能指标）
- 交互式预览让用户立即体验

**视觉特征**：
- 渐变或发光背景，暗示"智能"
- 代码块/Chat 界面作为视觉元素
- 微动效展示输出过程

**参考案例**：Kimi、ChatGPT、Claude

---

### 4. Content Hero（内容引导型）

**适用场景**：内容平台、媒体、社区、教育产品

**结构布局**：
```
┌──────────────────────────────────┐
│  标题 + 内容预览                  │
│  ┌───────────┐ ┌───────────┐    │
│  │ 精选内容  │ │ 推荐内容  │    │
│  └───────────┘ └───────────┘    │
│  搜索 / 分类导航                  │
│  下滑继续浏览                     │
└──────────────────────────────────┘
```

**关键元素**：
- 内容预览卡片（标题、摘要、封面）
- 搜索框或分类标签
- 个性化推荐暗示
- 低门槛 CTA（"免费阅读"、"注册获取更多"）

**视觉特征**：
- 卡片式布局，内容密度适中
- 封面图为主导视觉元素
- 字体层级清晰，便于扫描

## 模式选择指南

| 产品类型 | 推荐模式 | 原因 |
|---|---|---|
| 金融 / 大额交易 | Trust Hero | 信任比兴奋更重要 |
| SaaS / 工具 | Product Hero | 展示产品价值 |
| AI / 智能 | AI Hero | Demo 说服力最强 |
| 内容平台 | Content Hero | 内容质量是信任来源 |
| 电商 | Product Hero（适配） | 产品展示优先 |
| B2B 企业服务 | Trust Hero 或 Product Hero | 视行业属性而定 |

---

## Hero 设计检查清单

- [ ] 3 秒内能否理解业务是什么？
- [ ] 是否有明确的 CTA？
- [ ] 信任信号是否在首屏可见？
- [ ] 移动端是否适配（字体 clamp / 布局降级）？
- [ ] 是否有滚动引导？（下滑箭头 / 提示）
- [ ] 深色模式是否正常？
- [ ] 首屏加载时间是否在 2 秒以内？
- [ ] 文案是否传递了唯一的价值主张？
