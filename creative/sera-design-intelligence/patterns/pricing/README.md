# UI Pattern: Pricing Section

> 知识类型：pattern-library
> 版本：1.0.0
> 模式库分类：pricing
> 适用：SaaS 定价、套餐选择、会员方案、产品报价

---

## 模式概述

定价页的设计目标是：让用户快速理解价值差异，选择适合自己的方案，并降低决策焦虑。本库收录了四种核心定价模式，涵盖从标准化到定制化的不同定价策略。

---

## 模式变体

### 1. Tiered Cards（层级卡片式）

**适用场景**：SaaS 订阅、会员方案、标准化的产品套餐

**结构布局**：
```
┌──────────┐ ┌──────────┐ ┌──────────┐
│  Basic    │ │  Pro ⭐  │ │  Enterprise│
│           │ │          │ │           │
│  $9/mo    │ │  $29/mo  │ │  定制     │
│           │ │          │ │           │
│  ✓ 功能1  │ │  ✓ 功能1 │ │  ✓ 全部   │
│  ✓ 功能2  │ │  ✓ 功能2 │ │  + 定制   │
│           │ │  ✓ 功能3 │ │  + 支持   │
│           │ │  ✓ 功能4 │ │           │
│ [CTA]     │ │ [CTA]    │ │ [CTA]    │
└──────────┘ └──────────┘ └──────────┘
```

**关键元素**：
- 推荐方案（Pro）高亮（边框 / 标签 / 阴影）
- 功能对比清晰，逐行对齐
- 价格锚定（中间方案最推荐）
- 企业方案通常为"定制"→ 引导销售接触

**定价心理学**：
- 锚定效应：三个方案对比，中间方案最受欢迎
- 价值递进：功能逐级增加，用户自然向上选择
- 价格区分：显著差异让用户感受到升级的价值

**视觉特征**：
- 推荐方案卡片带品牌色边框（2px）或背景色区分
- 标签"最受欢迎"或"推荐"在推荐方案上方
- 推荐方案按钮与其它方案颜色不同
- 卡片阴影层次分明

**最佳实践**：
- 3 个方案是最佳数量（太少无对比，太多选择困难）
- 推荐方案放在中间（视觉重心）
- 年度价格突出"省 XX%"的折扣提示
- 功能列表用 ✓ 表示有，灰色 - 表示无

### 2. Comparison Table（对比表格型）

**适用场景**：功能差异显著的 SaaS、需要详细对比的产品、企业级方案

**结构布局**：
```
┌───────────┬───────┬───────┬───────┐
│ 功能      │ Basic │ Pro   │  Enterprise│
├───────────┼───────┼───────┼───────┤
│ 功能 1    │   ✓   │   ✓   │   ✓   │
│ 功能 2    │   ✓   │   ✓   │   ✓   │
│ 功能 3    │   —   │   ✓   │   ✓   │
│ 功能 4    │   —   │   ✓   │   ✓   │
│ 功能 5    │   —   │   —   │   ✓   │
├───────────┼───────┼───────┼───────┤
│ 价格      │  $9   │ $29   │ 定制  │
│           │ [CTA] │ [CTA] │ [CTA] │
└───────────┴───────┴───────┴───────┘
```

**关键元素**：
- 行标签（功能名称）清晰可扫描
- 列头（方案名称）固定，滚动时可见
- 推荐方案列高亮
- 关键差异点突出显示
- 最后一行放置价格和 CTA

**适用时机**：
- 功能差异较多，卡片式无法清晰展示
- 企业客户需要逐项对比评估
- 产品功能丰富，需要详细说明

**设计原则**：
- 行数不超过 15-20 行（过长则分组显示）
- 使用交替行背景色提升可读性
- 鼠标悬停行高亮
- 推荐方案列使用浅色背景高亮
- 移动端降级为卡片式或横向滚动

### 3. Usage-Based（按量计费型）

**适用场景**：API 服务、云服务、SaaS 用量计费、AI Token 计费

**结构布局**：
```
┌──────────────────────────────────┐
│  "按量付费，灵活扩展"              │
│                                   │
│  ┌──────────────────────────┐    │
│  │  用量计算器 / 预览        │    │
│  │  输入：10,000 请求/月     │    │
│  │  预估：$49/月             │    │
│  └──────────────────────────┘    │
│                                   │
│  免费层    按量层    企业层        │
│  $0        $X/unit   定制        │
│  1000 免费 无限用量   定制 SLA    │
└──────────────────────────────────┘
```

**关键元素**：
- 用量计算器（交互式预览费用）
- 清晰的单位定价（如 $0.01/次请求）
- 免费层 / 按量层 / 企业层三层结构
- 预估费用展示

**心理学原理**：
- 低门槛起步（免费层 + 按量付费）
- 透明度建立信任（用户知道自己付了什么）
- 渐进式付费（用户按需增长，减少决策压力）

**设计原则**：
- 计算器交互要实时反馈
- 单位定价数字要清晰放大
- 预估费用区间展示
- 免费层用量要慷慨，足以体验产品价值
- 用量上限提示（如"超出后按量计费"）

### 4. Custom Quote（定制报价型）

**适用场景**：企业级产品、高客单价服务、B2B 解决方案、定制化产品

**结构布局**：
```
┌──────────────────────────────────┐
│  "为企业量身定制"                  │
│                                   │
│  功能亮点：                        │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐          │
│  │  │ │  │ │  │ │  │ 能力展示    │
│  └──┘ └──┘ └──┘ └──┘          │
│                                   │
│  企业级功能清单                    │
│  - SSO / SAML                     │
│  - 审计日志                        │
│  - 专属 SLA                       │
│  - 定制集成                        │
│                                   │
│  ┌──────────────────────────┐    │
│  │ [联系销售]                │    │
│  └──────────────────────────┘    │
│                                   │
│  已有团队？[开始免费试用]          │
└──────────────────────────────────┘
```

**关键元素**：
- 企业级功能亮点展示
- 清晰的"联系销售"CTA
- 可选的"免费试用"入口（降低接触门槛）
- 企业客户案例 / 社会证明

**适用时机**：
- 定价无法标准化（定制化程度高）
- 企业客户需要销售接触（高客单价）
- 产品功能复杂，需要演示说明

**设计原则**：
- 提供足够的价值暗示，让客户愿意联系
- 企业客户案例展示（行业知名客户）
- 联系表单要简洁（减少填写摩擦）
- 提供试用选项（"先体验，再购买"）
- 响应速度承诺（"24 小时内回复"）

## 模式选择指南

| 产品类型 | 推荐模式 | 原因 |
|---|---|---|
| SaaS 订阅 | Tiered Cards | 标准化定价，决策路径清晰 |
| 功能丰富的产品 | Comparison Table | 差异点多，需要逐项对比 |
| API / 云服务 | Usage-Based | 用量灵活，按需付费 |
| 企业级服务 | Custom Quote | 定制化需求，需要销售介入 |
| 同时覆盖 SMB + Enterprise | Tiered Cards + Custom Quote | 自助 + 销售双通道 |
| 开发者工具 | Usage-Based + Tiered | 免费层 + 按量升级 |

---

## 定价心理学原则

### 锚定效应
展示三个方案，中间方案通常是最推荐的选择。用户会对比三个方案，而不是评估单个方案的价值。

### 降低决策焦虑
- 月付 → 年付（省 XX%）
- 免费试用（无风险体验）
- 随时取消（降低承诺感）
- 按量付费（用多少付多少）

### 价值感知
- 功能从"有/无"到"更多/更好"
- 价格数字放大、周期说明缩小
- 对比竞争产品时突出性价比

## 检查清单

- [ ] 是否有清晰的定价模式选择？
- [ ] 推荐方案是否视觉高亮？
- [ ] 价格数字是否足够大、易读？
- [ ] 功能对比是否清晰、可扫描？
- [ ] 是否有"免费试用"或"无风险"选项？
- [ ] 移动端是否可用（横向滚动 / 降级 / 卡片式）？
- [ ] 企业方案是否提供了联系销售路径？
- [ ] 是否有社会证明（客户案例、Logo）在附近？
- [ ] 货币符号和周期说明是否清晰？
- [ ] 年度 / 月度切换是否流畅？
