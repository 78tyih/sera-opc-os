# Sera Design Rules — 通用设计规则集

> 版本：v1.0
> 来源：HTX OTC Landing (financial-premium-landing-v1)
> 适用范围：金融科技 / SaaS 产品页面

---

## 1. 信息架构规则

### 1.1 页面必须回答的四个问题
1. 这是什么业务
2. 适不适合我
3. 怎么用（流程）
4. 下一步做什么（CTA）

### 1.2 信息优先级
```
首屏（业务是什么 + 价值主张 + CTA）
  ↓
服务介绍（适合谁）
  ↓
流程说明（怎么做）
  ↓
信任/合规（为什么要信任）
  ↓
FAQ（常见问题拦截）
  ↓
最终 CTA（立即行动）
```

### 1.3 内容组织原则
- 每个 Section 只讲一件事
- 每个 Section 有统一头部：标签 + 标题 + 副标题
- 卡片式布局，信息模块化
- 不把后台链路和合作方做成视觉焦点

## 2. 布局规则

### 2.1 容器系统
- 内容最大宽度：1120px（桌面）
- 水平 padding：24px → 16px（移动端）
- 板块间距：84px（桌面）→ 52px（移动）

### 2.2 栅格规则
- 3 列 grid：功能/服务卡片（每列等宽）
- 2 列 grid：双列布局（FAQ、合规卡片）
- 1 列 grid：单列内容（移动端自动降级）

### 2.3 卡片设计
- 卡片圆角：14px（标准）/ 12px（紧凑）/ 22px（突出卡片）
- 卡片内边距：28px（标准）/ 20px（紧凑）
- 卡片悬停：↑-3px + shadow-hover + border-color: brand
- 卡片背景：毛玻璃效果（`rgba(255,255,255,.62)` + `backdrop-filter:blur(14px)`）

---

## 3. 色彩规则

### 3.1 品牌色使用
- 蓝色作为核心交互色（按钮、链接、强调元素）
- 不做大面积渐变，保持品牌色纯净
- 品牌色在深色模式下提高亮度（+6 度）

### 3.2 语义色
- 警告/注意：黄色系（`#FFF8EC` bg + `#F5E3B8` border + `#8A6D1A` text）
- 成功：绿色系（`#EAF9F0` bg + `#16A34A` text）
- 错误：红色系（`#E5484D`）

### 3.3 深色模式
- 深色模式不是取反，是独立色彩映射
- 背景色：`#060708`（接近纯黑，非纯黑）
- 文字色：`#EDEFF3`（非纯白）
- 边框：`rgba(255,255,255,.1)`（半透明白线）
- 卡片背景：`rgba(22,24,29,.6)`（半透明深色毛玻璃）

## 4. 字体规则

### 4.1 字体栈
```css
font-family: -apple-system, BlinkMacSystemFont, "Helvetica Neue",
  "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

### 4.2 字号层级
- 主标题：clamp(44px, 6vw, 64px) — 800 weight
- 板块标题：clamp(44px, 6vw, 64px) — 800 weight
- 卡片标题：17-19px — 700 weight
- 正文：14-15px — 400 weight
- 辅助文字：13px — 400 weight
- 标签：12.5px — 700 weight, uppercase, 2px letter-spacing
- 最小可读：12px（风险提示）

### 4.3 排版规则
- 标题层级对比要强烈（主标题显著大于副标题）
- 标签使用 uppercase + letter-spacing 提升精致感
- 段落宽度不超过 660px（保持可读性）
- 行高：标题 1.14，正文 1.65

## 5. 动效规则

### 5.1 缓动函数
```css
/* Sera Ease — 所有动效统一使用 */
cubic-bezier(0.16, 1, 0.3, 1)
```

### 5.2 动效类型
| 类型 | 时长 | 用途 |
|---|---|---|
| 浮现入 | 0.72s | 页面滚动元素出现 |
| 悬停 | 0.3s | 卡片/按钮 hover |
| 展开 | 0.35-0.4s | FAQ 手风琴、更多展开 |
| 弹窗 | 0.35s | 弹窗出现 |
| 持续 | 2.4s infinite | 引导动画 |

### 5.3 动效原则
- 统一缓动：不用多个不同的缓动函数
- 克制：悬停仅上移+阴影，不做夸张效果
- 自然：浮现从下往上 + 淡入
- 性能：使用 CSS transition/animations，不依赖 JS 驱动

## 6. 转化规则

### 6.1 CTA 设计
- 首屏必须有 CTA（3 秒内可见）
- 每个 Section 结束提供"下一步"动作
- 主 CTA 使用品牌色填充按钮
- 次 CTA 使用文字链接或弱化按钮

### 6.2 表单设计
- 最小字段集：只收关键字段
- 分步收集：渐进式表单降低压力
- 弹窗形式：不跳转页面，保持上下文
- 逃生出口：提供"人工联系"替代方案

### 6.3 信任建立
- 信任标识在首屏可见（KYC/合规提示）
- 合规原则用"正面说明"语气，非"处罚条款"
- 风险提示使用小号文字，不制造焦虑

## 7. 组件模式

### 7.1 Section 标准结构
```html
<section>
  <div class="wrap">
    <div class="sec-head">
      <div class="sec-tag">LABEL</div>
      <h2>标题</h2>
      <p>副标题</p>
    </div>
    <div class="content-grid">
      <!-- 卡片内容 -->
    </div>
  </div>
</section>
```

### 7.2 卡片通用模式
```css
.card {
  background: rgba(255,255,255,.62);
  backdrop-filter: blur(14px);
  border: 1px solid var(--line);
  border-radius: var(--radius);
  padding: 28px;
  transition: all 0.3s cubic-bezier(.16,1,.3,1);
}
.card:hover {
  transform: translateY(-3px);
  box-shadow: var(--shadow-hover);
  border-color: var(--brand);
}
```

## 8. 响应式规则

### 8.1 断点
| 断点 | 规则 |
|---|---|
| >900px | 桌面端：完整布局 |
| ≤900px | 平板：导航链接隐藏，grid 降级 |
| ≤640px | 手机端：缩小字号、间距、卡片内边距 |

### 8.2 移动端适配原则
- 所有 grid 在移动端降级为 1 列
- 字体使用 clamp() 平滑缩放
- 触摸目标 ≥ 44px（按钮、链接）
- 移动端不减少模块，只压缩展示
- 导航栏在移动端保持功能完整

## 9. 设计合规原则

### 9.1 金融产品设计红线
- 不出现"保证收益""保本""秒到""免审核"等误导词
- 不暴露后台合作方、银行名称、内部资金路由
- 不以截图/回单替代实际到账确认
- 不承诺具体交易结果或到账时间
- 风险提示必须在页面页脚可见

### 9.2 文案语气
- 专业、克制、清晰
- 合规原则用"正面说明"语气
- 不使用"免责声明"堆砌
- 不制造焦虑或紧迫感
