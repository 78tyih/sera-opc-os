## 2. 视觉语言系统

### 2.1 卡片语言

卡是 Sera 视觉体系的核心容器。所有信息以卡片为基本单元组织。

**卡片规则**：
- 圆角 14px（标准）
- 白色背景 + 1px 细边框
- 毛玻璃效果（`backdrop-filter: blur(14px)`）
- 统一悬停动效（↑-3px + 阴影 + 边框变色）
- 深色模式下半透明深色背景

### 2.2 图标语言

**图标规则**：
- 线性图标（stroke-based）
- 描边宽度 1.8px
- 圆头端点（round cap）
- 品牌色描边
- 44×44px 标准尺寸
- 无填充背景

### 2.3 空间语言

**间距规则**：
- 板块间距 84px（桌面）→ 52px（移动）
- 卡片内边距 28px（桌面）→ 20px（移动）
- 内容 max-width 1120px
- 使用 8px 为基数的间距系统

### 2.4 边框语言

**边框规则**：
- 1px 细边框（`--line: #E8ECF2`）
- 蓝色边框用于强调（hover / 选中态）
- 左侧 4px 蓝色边框用于合规/原则卡片
- 深色模式下边框 `rgba(255,255,255,.1)`

### 2.5 阴影语言

**阴影规则**：
- 默认：极浅阴影（`0 2px 12px rgba(20,30,60,.05)`）
- 悬停：品牌色阴影（`0 10px 32px rgba(0,82,255,.10)`）
- 导航栏：`0 6px 24px rgba(20,30,60,.07)`
- 弹窗：`0 24px 64px rgba(10,25,80,.20)`
- 深色模式阴影加深

## 3. 视觉层级

### 3.1 页面层级

```
1. Hero 主标题  ─── 64px 800      → 第一视觉焦点
2. 板块标题     ─── 44-64px 800    → 第二视觉层级
3. CTA 按钮     ─── 品牌色填充      → 交互焦点
4. 卡片标题     ─── 17-19px 700    → 内容层级
5. 正文         ─── 14-15px 400    → 阅读层级
6. 辅助文字     ─── 13px 400 text2 → 次要信息
7. 风险提示     ─── 12px 400 text3 → 最小可读
```

### 3.2 卡片层级

```
图标（44×44）
  ↓ 14px gap
标题（17-19px 700）
  ↓ 4px gap
描述（14px 400 text2）
  ↓ 8-12px gap
CTA（14px 700 brand）
```

### 3.3 Section 头部层级

```
标签（12.5px 700 uppercase 2px spacing brand）
  ↓ 14px gap
标题（44-64px 800 -1.2px spacing）
  ↓ 10px gap
副标题（15px 400 text2）
```

## 4. 视觉系统交互

### 4.1 悬停状态

| 元素 | 悬停变化 |
|---|---|
| 卡片 | ↑-3px + shadow-hover + border-color: brand |
| 按钮 | brand-dark 背景 + ↑-2px + 品牌色阴影 |
| 链接 | 颜色变 brand |
| 导航链接 | 背景变 brand-soft |
| 图标 | 不变化（避免过度动效） |

### 4.2 选中/激活状态

| 元素 | 选中态 |
|---|---|
| 导航链接 | brand 色 + 600 weight |
| 切换按钮 | brand 填充 + 白色文字 |
| 表单输入 | brand 边框 + 3px brand 阴影 |

### 4.3 状态色彩

```
🟢 已完成  → 绿色 #16A34A
🔵 进行中  → 蓝色 #0052FF
⚪ 待启动  → 灰色 #8A93A6
🔴 已阻塞  → 红色 #E5484D
🟡 警告    → 黄色 #8A6D1A
```

## 5. 深色模式视觉语言

### 5.1 转换原则

- 深色模式不是亮色模式的取反
- 品牌色提高亮度（#0052FF → #3E8EFF）
- 背景色接近纯黑但不完全 (#060708)
- 文字色接近纯白但不完全 (#EDEFF3)
- 边框使用半透明白色

### 5.2 深色模式卡片

```css
[data-theme="dark"] .card {
  background: rgba(22, 24, 29, 0.6);
  border-color: rgba(255, 255, 255, 0.1);
}
```

### 5.3 深色模式阴影

```css
[data-theme="dark"] {
  --shadow: 0 2px 12px rgba(0, 0, 0, 0.35);
  --shadow-hover: 0 12px 34px rgba(62, 142, 255, 0.18);
}
```

## 6. 品牌应用规范

### 6.1 Logo 使用
- Logo 与品牌名保持 10px 间距
- 品牌名使用 800 weight + 18px
- 副标题使用 600 weight + 15px + text2 色

### 6.2 品牌色使用比例
```
黑色/深色 65%  → 文字、背景
白色 20%       → 亮色背景、卡片
蓝色 10%       → 交互元素、强调
语义色 5%      → 警告、错误、成功
```

### 6.3 品牌色禁止规则
- ❌ 大面积渐变
- ❌ 彩虹色
- ❌ 紫色和绿色作为主色
- ❌ 霓虹发光堆叠
- ❌ 复杂 3D 效果
