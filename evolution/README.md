# Evolution

> 进化系统 — 公司的自我改进和学习循环。

## 目录结构

```
evolution/
├── self-review/         # 自我审查
├── skill-discovery/     # 技能发现
├── failure-analysis/    # 失败分析
├── upgrade-proposal/    # 升级提案
└── experiment/          # 实验
```

## 每日自省

每天公司自动问：

```
1. 昨天哪里失败了？
2. 哪个 Agent 效率低？
3. 哪里可以自动化？
4. 应该学习哪个公司？
5. 哪些知识需要沉淀？
```

## 设计原则

- 每次失败必须有根因分析
- 每次成功必须有可复用资产
- 每个 Agent 必须有成长记录
- 每个季度必须有架构升级
