# Revenue

> 商业变现系统 — 收入引擎。

## 目录结构

```
revenue/
├── crm/               # 客户关系管理
├── sales/             # 销售管道
├── affiliate/         # 联盟营销
├── growth/            # 增长策略
├── customer-success/  # 客户成功
└── analytics/         # 收入分析
```

## 核心指标

| 指标 | 说明 |
|------|------|
| Revenue | 总收入 |
| Pipeline | 销售管道价值 |
| Conversion Rate | 转化率 |
| CAC | 客户获取成本 |
| LTV | 客户生命周期价值 |
| Retention | 留存率 |
