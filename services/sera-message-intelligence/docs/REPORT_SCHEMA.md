# Personal Intelligence Brief Contract

The report engine is intentionally not implemented in the first Message Core commit. Its target output is one cross-group brief, not one report per chat.

Planned fields: executive_summary, must_handle, important, actions, decisions, opportunities, risks, people_to_reply, resources, knowledge, topics, group_appendix.

Every derived item must contain title, summary, importance_score, confidence, and sources. Each source must preserve platform, account, conversation, and original message IDs so any claim can be traced back to evidence.
