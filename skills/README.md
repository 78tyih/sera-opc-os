# Skills

> 技能目录 — 所有可复用的技能定义。

## 目录结构

将 `business/`、`creative/`、`product/` 中的技能按类型组织：

```
skills/
├── analysis/           # 分析技能
├── creative/           # 创意技能
├── marketing/          # 营销技能
├── sales/              # 销售技能
├── product/            # 产品技能
├── engineering/        # 工程技能
└── operations/         # 运营技能
```

## 引用

现有技能仍然在 `business/`、`creative/`、`product/` 目录中。
此目录为统一索引，方便 Router 发现和调度。
