# Benchmark Library

每个部门绑定世界级组织作为学习标杆。

```yaml
departments:
  strategy:
    benchmark: [McKinsey, BCG]
    focus: 战略咨询、市场分析、商业机会发现

  product:
    benchmark: [Apple, OpenAI]
    focus: 产品思维、用户体验、极简设计

  engineering:
    benchmark: [Google, Meta]
    focus: 工程体系、代码质量、基础设施

  design:
    benchmark: [Apple Design, Figma]
    focus: 设计系统、品牌体验、视觉一致性

  operations:
    benchmark: [Toyota]
    focus: 持续改进、精益生产、流程优化

  sales:
    benchmark: [Salesforce]
    focus: 销售体系、CRM、客户成功

  marketing:
    benchmark: [Tesla, Nike]
    focus: 品牌建设、内容营销、社区运营

  ai_research:
    benchmark: [OpenAI, Anthropic, DeepMind]
    focus: 前沿 AI 研究、模型能力、安全对齐
```
